# CH6 공부노트

> 💡델리게이트란?
> 
- 중학교 수준으로 비유하자면 "구독과 알림 설정"입니다. 특정 객체(예: AI 컴포넌트)가 "나 추론 끝났어!"라고 외치면, 그 소식을 구독(Bind)해 둔 다른 객체들(UI, 캐릭터 애니메이션 등)이 알아서 각자의 행동을 실행하게 만드는 C++ 시스템입니다. 서로의 헤더 파일을 몰라도(결합도를 낮춰서) 통신할 수 있게 해주는 핵심 기능입니다.

1. 종류와 차이

| 종류 | 특징 | 비유 | 언리얼 실무 사용처 |
| :--- | :--- | :--- | :--- |
| **Single-cast** | 1:1 통신. 딱 하나의 함수만 연결 가능. | 개인 톡방 | 리턴 값이 필요한 특정 콜백 로직 (가장 기본형) |
| **Multi-cast** | 1:N 통신. 여러 개의 함수를 동시에 연결 가능. | 단체 공지방 | 보스 사망 시 -> 문 열림 + UI 알림 + 효과음 재생 등 여러 객체가 동시에 반응해야 할 때 |
| **Dynamic** | 직렬화(Serialization) 가능. | 블루프린트 호환 | 블루프린트와 C++을 섞어 쓸 때 필수. (단, 실행 속도는 일반 델리게이트보다 미세하게 느림) |
| **Dynamic Multi-cast** | 블루프린트에서 Event Dispatcher로 쓰이는 그것. | 최강의 호환성 | 에픽게임즈가 제공하는 대부분의 컴포넌트 이벤트(`OnComponentHit` 등)가 이 방식.|
